1. 为什么“只做小流量”能够提升网络使用体验？

在机场行业中，许多运营商为了吸引眼球，往往推出 500GB、1000GB 甚至无限制的大流量套餐。然而，这类“大桶饭”式的服务必然会导致部分用户将其用于 BT/PT 磁力下载、批量网页爬虫或高并发自动化脚本测试。其直接后果是：出口 IP 频繁遭遇 Cloudflare 弹出人机九宫格验证码、OpenAI 官方封禁 ASN、Netflix 识别代理拒绝播放，且晚高峰公网带宽被少数重度用户吃满。

鲤云机场反其道而行之，通过将流量上限控制在每月 100G - 200G 之间，天然过滤掉了 P2P 滥用与高负载爬虫群体。节点流量负载保持在健康水平，出口 IP 信誉评分极高，为精细化出海、AI 对话（ChatGPT/Claude）以及高清视频秒开提供了极为干净的网络土壤。

2. 海外中转架构 vs 传统直连 VPS 的硬核优势

普通廉价机场由于预算限制，往往直接采购单价极低的海外 VPS 搭建直连节点（如公网直连香港或美国 VPS）。在白天非高峰期尚能勉强维持，一旦进入晚上 8 点至 11 点的国际公网高峰期，三大运营商的国际出口互联点（GZ/SH/BJ）便会出现严重拥堵，直连链路的丢包率常常暴涨至 30% 以上，出现严重的打字卡顿、网页超时现象。

鲤云底层采用了“海外中转优化线路”。在国内前端通过优质入口节点进行数据汇聚与协议封装，再通过专用的海外中转跳板输送至目标机房。这种架构不仅能够平滑国内电信、联通、移动三大运营商的网络抖动，更能显著降低数据包在国际公网上的丢包率，大幅提升晚高峰期间的链接稳定性。

五、核心技术：AnyTLS 伪装协议详解与客户端极速排错指南

部分初次使用的用户在导入订阅后可能遭遇“节点全部显示超时（Timeout）”或“有延迟响应但网页打不开”。官方公告明确指出了原因：旧版软件不支持 AnyTLS 新协议。

1. AnyTLS 协议的技术优势与版本要求

AnyTLS 协议通过优化的 TLS 握手特征伪装，大幅降低了中转链路被识别阻断的概率，但必须配合支持新一代内核（如 Sing-box 内核或最新 Xray-core）的客户端。切勿使用已停更的老旧客户端（如老旧版 Clash for Windows、过旧的 V2rayN）。

推荐客户端：前往官方文档或代理软件专用页面下载最新版 Clash Verge Rev（桌面端）、Clash Meta / Flclash（全平台） 或 Shadowrocket（iOS）。

2. 常见连接问题解决步骤

电脑端（Clash Verge Rev）节点超时或无网络解决办法：
  1. 打开 Clash Verge Rev 客户端，进入左侧 【设置 (Settings)】；
  2. 找到 【DNS 覆写 (DNS Override)】 选项并切换为 开启 (Enable)；
  3. 将远端 DNS 设为纯净 TLS/HTTPS 公共 DNS（如 tls://8.8.8.8 或 https://1.1.1.1/dns-query）；
  4. 点击右下角刷新节点延迟，重新开启【系统代理 (System Proxy)】即可。
安卓端（Clash Meta / CMFA / Flclash）刷新无延迟解决办法：
  1. 进入 App 的 【设置】 -> 【覆写 / Overrides】；
  2. 找到 【策略组 (Policy Group)】 选项，切换为 【使用内置 (Built-in)】；
  3. 彻底结束应用后台进程，重启软件即可完全恢复正常连接。

答：鲤云定位为“纯小流量生态”，单月最高仅 200GB 流量，严禁 BT/PT 下载和大文件滥用，因此不适合游戏大文件更新或网盘同步，但对于日常出海办公、AI 对话及巴哈姆特追剧非常流畅。

问：为什么导入订阅后无法连接或提示 Timeout？

答：鲤云服务端启用了 AnyTLS 新伪装协议，需使用最新版 Clash Verge Rev、Clash Meta 或 Flclash 等现代客户端，并在设置中开启“DNS 覆写”，把远端 DNS 改为 pure tls://8.8.8.8 即可解决。

问：鲤云机场有优惠码吗？

答：有的，结账时输入官方 8 折优惠码 liyun888 即可享受全单 8 折极致折扣。
